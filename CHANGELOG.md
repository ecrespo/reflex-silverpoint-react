# Changelog

All notable changes to `reflex-silverpoint-react`. The format follows
[Keep a Changelog](https://keepachangelog.com/en/1.1.0/); versions follow
[Semantic Versioning](https://semver.org/).

## [0.8.0] — 2026-10-21

Wraps **`@silverpoint/react` 0.8.0** (0.7.1 wrapped 0.7.0). silverpoint 0.8 adds agent access (its
feature-005: the agent catalog, `@silverpoint/mcp` and the skills) and changes no API of
`@silverpoint/react`, `core`, `grounds` or `fonts`; the Python builders are unchanged.

### Changed

- `SILVERPOINT_VERSION` is `0.8.0`; every npm dependency is pinned to it.

### Added

- `reflex-catalog.json` and `scripts/export_catalog.py` (silverpoint T-230, Data Model §2.30): the
  Reflex catalog silverpoint's agent catalog joins, with each builder's snake_case props, their JS
  names and the deprecated arguments it still accepts. CI fails when it is stale, and each GitHub
  release carries it.
- The **`reflex-silverpoint` skill** (`skills/reflex-silverpoint/`, silverpoint T-246): builders,
  props, State patterns and events, provider and palettes, composed components and overlays, the
  dashboard and the timeline, generated by `scripts/make_skill.py` from hand-written templates and
  the catalog. CI imports and renders every Python example of the skill.
- A **Claude plugin** (`.claude-plugin/`, silverpoint T-248): the skill plus the hosted silverpoint
  MCP server, `https://silverpointweb.vercel.app/mcp`.

### Fixed

- `CHARTS` documents `on_root_change` for `squarified_treemap` and `sunburst_chart` (it was declared
  on a private base class and missing from their props reference).

## [0.7.1] — 2026-10-20

Wraps **`@silverpoint/react` 0.7.0** (0.7.0 wrapped 0.6.0). silverpoint 0.7 took this package's
palettes, composed components, overlays and timeline into the library (its feature-004), so they are
now the npm components instead of Reflex-composed copies. The Python builders keep their 0.7.0
signatures.

### Changed

- `SILVERPOINT_VERSION` is `0.7.0`; every npm dependency is pinned to it.
- **Palettes** are the npm `palette` prop (camelCase fields), merged element → dashboard → provider
  field by field. `silverpoint_provider(palette=...)` is accepted; `silverpoint_palette(...)` is a
  provider with a palette. A dashboard's palette now reaches its charts.
- `check_palette()` measures the core's `PALETTE_PAIRS` (adds the focus ring, defaulting to `ink`,
  and the heightening's outline and text pairs). `"ironGall"` resolves to the `iron_gall` preset.
- `sp_surface`, `sp_glyph`, `sp_pagination`, `sp_input_number` and the composed components (`sp_table`,
  `sp_breadcrumb`, `sp_avatar`, `sp_avatar_group`, `sp_statistic`, `sp_descriptions`,
  `sp_timeline_list`, `sp_collapse`, `sp_collapse_item`, `sp_empty`, `sp_result`, `sp_textarea`) are the
  npm components; they read `silverpoint_provider`. `sp_surface` no longer forwards unknown DOM
  attributes (the npm `SpSurface` has none).
- Overlays (`sp_modal`, `sp_drawer`, `sp_popover`, `sp_tooltip`, `sp_select`, `sp_dropdown_menu`,
  `sp_toast`, `sp_toaster`) are the npm components on `<dialog>` and the Popover API, in place of
  Radix primitives; they render in place and read the provider.
- `sp_trigger` is `SpTrigger`, a native button drawn by the core's `uiButtonView` that keeps the ARIA
  and handlers an overlay clones onto it (the npm `SpButton` 0.7.0 drops them).
- `sp_timeline` is the npm `SpTimeline`; `@knight-lab/timelinejs` 3.9.13 is its npm dependency. The
  `[timeline]` extra is empty (kept for compatibility); `timeline_available()` is always `True`.
- `sort_rows()` follows `uiSortRows`: numbers first, then text by code point after lower-casing.
- `sp_collapse_item(on_toggle=)` receives the new open state (a bool), not the DOM event.
- `silverpoint_palette()` lives in `base` next to `SilverpointProvider`, which ends the
  `base` ↔ `palette` import cycle; import it from `reflex_silverpoint_react`, not from
  `reflex_silverpoint_react.palette`.

### Added

- `sp_modal(label=, dismissible=)`, `sp_drawer(extent=, label=, dismissible=)`, `sp_popover(offset=,
  label=)`, `sp_tooltip(offset=)`, `sp_select(open=, default_open=, on_open_change=)`,
  `sp_dropdown_menu(label=)`, `sp_descriptions(heading_level=)`, `sp_result(heading_level=)`,
  `sp_table(row_key=)`, `sp_timeline(label=, fallback=)`.
- The component classes (`SpTable`, `SpModal`, `SpTimeline`, `SpTrigger`…), `palette_prop`,
  `PALETTE_JS_FIELDS`, `PALETTE_PAIRS`, `TIMELINEJS_VERSION`.

### Deprecated

- `side="left"`/`"right"` (use `"start"`/`"end"`), `position="bottom-right"`… (use `"bottom-end"`…),
  `sp_drawer(size=)` (`extent=`), `sp_popover(side_offset=)`/`sp_tooltip(side_offset=)` (`offset=`),
  `sp_textarea(textarea_id=)` and `sp_input_number(input_id=)` (`id=`), `sp_toast(action_alt=)`
  (ignored).

### Removed

- The Radix primitives, `RADIX_VERSIONS`, and the assets `surface.jsx`, `surfaces.css`,
  `timeline.jsx`, `timeline.css`; the `reflex-knightlab-timeline` dependency.
- `sp_textarea(on_blur=)` raises `TypeError` (the npm `SpTextarea` has no blur event).
- `sp_tooltip` content must be text (`SpTooltip.text`).

## [0.7.0] — 2026-10-18

### Added

- **Palettes**: `palette=` on every chart, UI component, dashboard and composed component;
  `Palette`, `PALETTES` (presets `silverpoint`, `sanguine`, `sepia`, `iron_gall`, `verdigris`,
  `indigo`), `silverpoint_palette(...)` for a whole section, `check_palette()`, `contrast_ratio()`,
  `palette_css()` and `PALETTE_PROPERTIES`.
- **Composed components, level A** (native markup on silverpoint surfaces): `sp_table` (+
  `sort_rows`), `sp_pagination`, `sp_breadcrumb`, `sp_avatar` (+ `sp_avatar_group`),
  `sp_statistic`, `sp_descriptions`, `sp_timeline_list`, `sp_collapse` (+ `sp_collapse_item`),
  `sp_empty`, `sp_result`, `sp_textarea`, `sp_input_number`.
- **Composed components, level B** (overlays on Radix primitives): `sp_modal`, `sp_drawer`,
  `sp_popover`, `sp_tooltip`, `sp_select`, `sp_dropdown_menu`, `sp_toast` (+ `sp_toaster`) and
  `sp_trigger`.
- **`sp_timeline`**: Knight Lab TimelineJS drawn in silverpoint (optional extra
  `reflex-silverpoint-react[timeline]`), plus `timeline_available()`.
- `sp_surface` and `sp_glyph`, the building blocks of the composed components.
- `scripts/make_stubs.py` to regenerate the `.pyi` stubs.
- Demo pages `/components`, `/palettes` and `/timeline`; palette control on Gallery and Playground.
- `AGENTS.md`, `CLAUDE.md`, `CHANGELOG.md` and a `.pre-commit-config.yaml` mirroring CI.

### Changed

- Requires **Reflex 0.10.0** and therefore **Python 3.11+** (CI matrix 3.11–3.13).
- The package ships `assets/*.jsx` and `assets/*.css` as package data.

### Removed

- Python 3.10 support. `reflex component build` (removed by Reflex 0.10) is replaced by
  `scripts/make_stubs.py` + `uv build`.

## [0.6.0]

- 27 new charts (silverpoint 0.6 second catalog) — 60 in total — and drill-down on
  `squarified_treemap` and `sunburst_chart` (`root_id`, `on_root_change`).

## [0.3.0]

- The 17 `Sp` UI components, `UI_COMPONENTS`, `UI_DEMOS`, `ui_demo()`; `substrate="prussian"`.

## [0.2.0]

- `dashboard`, `dashboard_cell`, `dashboard_link`; the `cyanotype` ground.

## [0.1.0]

- First release: the silverpoint charts, `SilverpointProvider`, events, readouts and the
  imperative handle (SVG export, geometry).
